- Разбор строки заголовка таблицы (`HeaderParser`): типы, массивы, обязательность, пропуск `#`, ошибки с адресом ячейки.

- Разбор значений ячеек по типу столбца (`CellValueParser`): умолчания для пустых ячеек, обязательные столбцы, массивы с экранированием `\|`, числа в инвариантной культуре, все ошибки строки с адресом ячейки.
